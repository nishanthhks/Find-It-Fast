# Find It Fast

**Find It Fast** is a **Flutter + Firebase** mobile application built to simplify **lost and found tracking** within an organization or campus. Designed with both accessibility and administration in mind, it enables users to report and locate lost items while giving **admins control over item recovery workflows**.

## 🔍 Features

### 📱 Core Functionality
- Seamlessly **submit and browse lost/found items**.
- Each submission is categorized with metadata like location, description, and timestamp.
- Real-time **updates via Firebase** keep everyone in sync.

### 👮 Admin Features
- Admins can **verify, manage, and mark items as returned**.
- Clean, structured catalog system for **efficient tracking** and **manual overrides**.

### 🔐 Authentication & Data
- Secure **Firebase Authentication** with role-based access for admins and students.
- **Firestore database** used for item storage with real-time sync.
